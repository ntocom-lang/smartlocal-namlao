# ระบบน้ำของตำบล (ฤดูแล้ง เฟส 5 · PR 5.2 น้ำเลา · PR 5.3 ตำหนักธรรม + ทุ่งแค้ว)

> **2569-10-24 (เจ้าของระบบสั่งจัดระเบียบ 2 แท็บ) — โครงหน้าด้านล่างเปลี่ยนแล้ว:** ส่วนนี้ไม่ได้อยู่ท้ายแท็บสถานการณ์อีกต่อไป (ยาว 1,431–1,601px ท้ายสุด และเล่าเรื่องเดียวกับภาพผังน้ำตำบลซ้ำสองรอบ · มีคำกำกับ/ที่มาสองชุด · ตัวเลขเริ่มไม่ตรงกัน เช่น ทุ่งแค้ว โปสเตอร์ "แผนก่อสร้าง 2 · ชำรุด 1" แต่ส่วนนี้ "แผนก่อสร้าง 3 · รางชำรุด 2 จุด" นับคนละหน่วย)
> - **ก่อนถึงตำบล** + **ไหลต่อไปที่** ย้ายไปใต้ภาพในแท็บ **ผังน้ำตำบล** (`WaterDiagramEdges.jsx` · เฉพาะแท็บย่อย "แผนภาพ" · แสดง 3 รายการแรก "ดูทั้งหมด N รายการ" · ข้อความ "ผังไม่ระบุ" เส้นประเหลือง "ไม่มีค่าสดในระบบ" คงเดิม)
> - ขั้น **ในตำบล ตัดออกจากหน้า** (ซ้ำกับภาพและ "รายการจุด") — ข้อมูล `inside` ยังเก็บในทะเบียน (เทสต์ความสอดคล้องกับผังเคลื่อนไหวเดิมยังใช้) ลบพร้อมงานลบโค้ดภาพเกาะลอย
> - **คำกำกับบังคับ · อายุผัง · ที่มา เหลือชุดเดียว** ใน `WaterDiagram.jsx`: คำกำกับของผัง + "ไม่ใช่ประกาศ · ไม่บอกเวลาน้ำถึง · ไม่ได้รับรองว่าปลอดภัย" ("ไม่ได้แสดงว่ามีน้ำไหลจริง" ผังพูดไว้แล้ว ไม่พูดซ้ำ) · บรรทัด "ผังต้นฉบับอายุ N ปี M เดือน" + แถบเหลืองที่ 36 เดือน (`diagramAge`) · แท็บ "ที่มา": "ผังต้นฉบับของตำบลนี้วาดไว้: อ่าง/ฝาย/หนอง/ห้วยสาขา" (`systemCountsText` **ไม่นับแผนก่อสร้าง** — เลขแผนก่อสร้างอยู่แถบหัวภาพ นับจากผังเดียวกับภาพ) + ที่มาของก่อนถึงตำบล/ไหลต่อไปที่
> - **ป้ายความสัมพันธ์** บนการ์ดอ่าง/ระดับน้ำ (ต้นน้ำของตำบล · อยู่ในตำบล · สายข้างเคียง · ผังไม่ระบุ) **ยังอยู่แท็บสถานการณ์เหมือนเดิม** (ใช้ `resolveSystem` + `?system=` เหมือนเดิม)
> - ผังที่มี route ทุกตัวต้องมีระบบน้ำ id เดียวกัน (เทสต์ตรึง) ไม่งั้น "ก่อนถึงตำบล/ไหลต่อไปที่" หาย
> - ตารางผลที่ถอดด้านล่างยังเป็นบันทึกของทะเบียน (แถว "ในตำบล" ไม่ขึ้นหน้าเว็บแล้ว)

ส่วน "ระบบน้ำของตำบล" บนหน้า `/water-situation` — ตอบว่า **น้ำไหลมาจากไหน ผ่านอะไรในตำบล และไหลต่อไปที่ไหน** ตามผังของศูนย์บริหารจัดการน้ำจังหวัดแพร่
เจ้าของระบบสั่ง 2569-10-18: ใช้ผังน้ำจังหวัดแพร่ + ผังน้ำตำบลของ อปท. นั้นเป็นหลัก · ออกแบบให้จบ ไม่ต้องถามซ้ำ (ดีไซน์ฉบับปิด D1–D22 สรุปด้านล่าง)

## ใครเห็น
`WATER_SYSTEM_TENANTS` (`src/lib/waterSystem/model.js`) — **น้ำเลา** (ใช้งานจริง) · **ตำหนักธรรม** และ **ทุ่งแค้ว** (เตรียมขาย ยังไม่ใช้งานจริง ได้ระบบของตัวเอง) · **demo** (ค่าเริ่มต้น = ระบบของน้ำเลา ติดป้าย "ข้อมูลจริงของน้ำเลา ใช้สาธิต")
อปท. ที่ไม่อยู่ในทะเบียนไม่เห็นหัวข้อนี้เลยและไม่โหลดโค้ดส่วนนี้ (lazy) · `?system=<id>` ใช้ได้เฉพาะ demo — อปท. จริงเมินเสมอ
ดูระบบของตำหนักธรรม/ทุ่งแค้วบน demo ได้ที่ `?system=tamnaktham` / `?system=thungkaew` (ป้าย "ตัวอย่างบนสนามซ้อม · ค่าสดคือสถานีที่สนามซ้อมติดตาม") · อปท. จริงเห็นเฉพาะระบบของตัวเอง ใส่ `?system=` อะไรก็เมิน

## โครงหน้า (3 บล็อกของส่วนนี้ + ผังเคลื่อนไหวเดิม)
1. หัว + คำกำกับบังคับ ("ไม่ใช่ประกาศ · ไม่บอกเวลาน้ำถึง · ไม่ได้แสดงว่ามีน้ำไหลจริง · ไม่ได้รับรองว่าปลอดภัย") + อายุผัง
2. ภาพรวม 3 ขั้น: **ก่อนถึงตำบล** → **ในตำบล** → **ไหลต่อไปที่** (มือถือเรียงแนวตั้ง ย่อเหลือ 3 รายการ "ดูทั้งหมด N รายการ" · PC 3 คอลัมน์)
3. ที่มาและอายุของข้อมูล + ลิงก์ผังต้นฉบับ

(ผังเคลื่อนไหวเดิม `WaterDiagram` · PR #482 อยู่ถัดลงไป — ไม่แตะ)

**ตัดออกแล้ว 2569-10-19 (เจ้าของระบบสั่ง เห็นจากหน้าน้ำเลาจริง):** (ก) การ์ดแนวโน้มอ่าง 30 วัน — ซ้ำกับการ์ดอ่างเดิมของหน้า (ป้ายต้นน้ำ · ปริมาตร · คำเตือนตัวเลขซ้ำเดิมอยู่ที่นั่นอยู่แล้ว) เหลือแต่กราฟเส้นเรียบที่ไม่บอกอะไรเพิ่ม (ข) กล่อง "ผังต้นฉบับมี แต่เราไม่ได้ใส่" — ภาษาเทคนิคเกินไปสำหรับชาวบ้าน · ใช้กับทุก อปท. ที่มีส่วนนี้ (น้ำเลา ตำหนักธรรม ทุ่งแค้ว) เพราะเป็นคอมโพเนนต์เดียวกัน · **ล็อกด้วยเทสต์ว่าไม่กลับมา และหน้าไม่เรียก `get_public_dam_history` อีก** (ลดคำขอ 1 ครั้งต่อการเปิดหน้าของน้ำเลา)
- รายการ "ที่ผังมีแต่ไม่ได้ใส่" **ยังเก็บในทะเบียน** (`omitted` ของ `src/lib/waterSystem/*.js`) เป็นบันทึกให้ อบต. ยืนยัน (ดูหัวข้อ "ที่ต้องให้ อบต. ยืนยัน") แต่ไม่ขึ้นหน้าเว็บ
- ฟังก์ชัน `get_public_dam_history` และการเก็บค่าอ่าง 400 วัน ([PR 5.1](water-dam-history.md)) **คงไว้** (ไม่แตะฐานข้อมูล) เผื่อใช้ภายหลัง — ตอนนี้ไม่มีหน้าไหนเรียก
- ถ้าจะนำแนวโน้มกลับมา ต้องออกแบบไม่ให้ซ้ำกับการ์ดอ่างเดิม (เช่น ใส่กราฟในการ์ดอ่างเดิมเอง)

การ์ดอ่าง/ระดับน้ำเดิมบนหน้าได้ **ป้ายความสัมพันธ์** (ต้นน้ำของตำบล · อยู่ในตำบล · ปลายน้ำของตำบล · สายข้างเคียง · ผังไม่ระบุ) + คำอธิบายใต้ชื่อเมื่อเป็นสายข้างเคียง/ผังไม่ระบุ — อปท. ที่ไม่มีระบบ การ์ดคงเดิมทุกอย่าง (ภาพแชร์ไม่เปลี่ยน)

## ตำหนักธรรม: ผลที่ถอด (PR 5.3 · ตามผัง)
ตำบลไม่มีอ่างเก็บน้ำของตัวเอง และอ่างขนาดกลางที่เคยตั้งค่าไว้ (แม่คำปอง/แม่ถาง) ถูกปิดแล้วใน PR 5.1 → ไม่มีการ์ดอ่าง · เรื่องสองอ่างนี้จดไว้ใน `omitted` ของทะเบียน (ไม่ขึ้นหน้าเว็บ)
| ขั้น | เนื้อหา |
|---|---|
| ก่อนถึงตำบล | ลำห้วยแม่คำมี (ต.ร้องเข็ม ต้นสายติด ต.ทุ่งศรี มีฝายร้องเข็ม · ฝายห้วยบาตร) · ลำห้วยปางจ๊าว/ลำห้วยเต่า (อ่างบ้านใหม่จัดสรรอยู่ต้นสาย · อ่างปางจ๊าวเขียนสีแดง = แผน) · **ผังไม่ยืนยัน (เส้นประ)**: "น้ำแม่คำมี" ของผังตำหนักธรรม = "ลำห้วยแม่คำมี" ของผังร้องเข็ม/แม่คำมีหรือไม่ · อ่างต้นสายตามผังจังหวัด (ไม่มีค่าสดในระบบ) · ต้นทางของคลองชลประทานแม่ยมฝั่งซ้าย |
| ในตำบล | น้ำแม่คำมี + สถานีระดับน้ำ Y.38 (**ค่าสด**) · ฝายบนสาย 4 (เวียงม่วง · ม.5 · ม.3 · ไม่ระบุชื่อ 1) + ฝายเล็กบนร่อง 2 · ฝายตามแผน 2 (ม.1 · ม.12) · สถานีสูบตามแผน 3 · ห้วยเคี่ยน/ร่องซิง/ร่องปู่แจ้/ห้วยหาด · คลองชลประทานแม่ยมฝั่งซ้าย (ตัดผ่านน้ำแม่คำมี ผังไม่ระบุว่ารับน้ำหรือไม่) · ประตูระบายน้ำ · ประปาหมู่ 1 |
| ไหลต่อไปที่ | แม่น้ำยม · ลำห้วยแม่คำมีเป็นแนวแบ่งกับ ต.แม่คำมี (ผังแม่คำมี) · คลองชลประทานฝั่งซ้าย → ต.แม่คำมี → ต.แม่หล่าย |
| ป้ายบนการ์ด | Y.38 = อยู่ในตำบล · YOM003 (6.6 กม.) = ผังไม่ระบุ (ผังไม่ระบุว่าอยู่เหนือหรือใต้จุดที่น้ำแม่คำมีลงแม่น้ำยม) |
| ผังขัดกัน | ฝาย ม.12: ผังตำหนักธรรมวาดสีแดง (แผนก่อสร้าง) ผังแม่คำมีวาดสีน้ำเงิน (ซ่อมแซม) → ใช้ผังของตำบลตัวเอง จดไว้ใน `omitted` ของทะเบียน ไม่ตัดสินแทน |

## ทุ่งแค้ว: ผลที่ถอด (PR 5.3 · ตามผัง)
ไม่มีอ่างขนาดกลางใน ThaiWater → ไม่มีการ์ดอ่างกลาง · ตำบลเพื่อนบ้านไม่ได้ถอด (ผังเริ่มห้วยทั้ง 3 ลุ่มที่ขอบบนของตัวเอง)
| ขั้น | เนื้อหา |
|---|---|
| ก่อนถึงตำบล | ฝายแม่ยม (ฝายคอนกรีตขนาดใหญ่) อ.สอง ต้นทางของคลอง (ผังจังหวัด + ชื่อคลองในผังตำบล) · แม่น้ำยมตามขอบล่าง · **ผังไม่ยืนยัน (เส้นประ)**: ห้วยโป่งนก/ห้วยม่วง (ซ้าย ติด ต.น้ำรัด) · ต้นสายห้วยเฮือ/ยอย/ปุ่ย (ขอบบน ติด ต.เวียงต้า อ.ลอง) |
| ในตำบล | อ่าง 3 (ห้วยเฮือ — ไม่มีค่า · ห้วยยอย/ห้วยปุ่ย — **รายงานรายสัปดาห์ของศูนย์ฯ ไม่ใช่ค่าสด** ไม่ขึ้นป้ายค่าสด/ไม่มีค่าสด เพราะมีการ์ดอ่างเล็กของตัวเองบนหน้า) · ฝนที่อ่างห้วยยอย RES038 (**ค่าสด**) · ฝาย ~27 · ห้วยสาขา ~23 · หนอง 3 + ประตูน้ำ · คลองชลประทานฝายแม่ยมฝั่งขวา (ลูกศรสองปลาย ไม่ระบุทิศ) · รางส่งน้ำชำรุด 2 · แผน: สถานีสูบ 2 + โครงสร้างกรอบแดงประ 1 · ประปา ม.1/ม.4 |
| ไหลต่อไปที่ | แม่น้ำยม (ห้วยทั้ง 3 ลุ่มไหลลง) · ปลายทางของคลองฝั่งขวา (**ผังไม่ยืนยัน**) |
| ป้ายบนการ์ด | YOM003 (4.8 กม.) = ผังไม่ระบุ (ผังตำบลไม่ได้วาดสถานีนี้ ไม่อยู่ในขั้น "ไหลต่อไปที่") |
| ข้อจำกัดข้อมูล | ⚠️ การ์ดอ่างเล็กห้วยยอย/ห้วยปุ่ย: ศูนย์ฯ แพร่ตอบ 403 ให้ IP ต่างประเทศ (รวม Cloudflare) ตั้งแต่หลัง 16 ต.ค. 2569 — สำเนาเก่าใช้ได้ถึง ~30 ต.ค. แล้วการ์ดจะขึ้น "ไม่มีข้อมูล" (ไม่เกี่ยวกับส่วนนี้ ส่วนนี้ไม่พึ่งค่าอ่างเล็ก) |

## กติกา (ล็อกด้วยเทสต์ `tests/water-system.test.mjs`)
- **ไม่คัดลอกความจุจากผัง** — ผังขัดกับรายงานจริง (เช่น แม่สงอนใน 1.165 ในผัง / 0.211 ในรายงาน; ผังเขียน 1.165 ซ้ำสองอ่าง) ใช้ตัวเลขจากแหล่งค่าสดเท่านั้น
- **ไม่เดา** — ความสัมพันธ์/ทิศ/จุดต่อที่ผังไม่ระบุ = `status: 'unconfirmed'` เส้นประ + ป้าย "ผังไม่ระบุ" · ต้นน้ำไล่ลึก 2 ชั้นตามผังตำบลเพื่อนบ้านที่ศูนย์ฯ ทำไว้ เกินนั้นเขียน "ต้นน้ำอยู่ไกลกว่านี้ ผังที่ใช้ไม่ครอบคลุม"
- **ค่าสด**: มีสถานี/รายงาน = "ค่าสด" · ไม่มี = **"ไม่มีค่าสดในระบบ"** (ข้อความเดียวทั้งระบบ) · ไม่เขียน "ปกติ" ไม่เติมเลข · ค่า 0 จริงยังเป็น 0
- **ไม่มีแนวโน้มอ่างในส่วนนี้** (ตัดออก 2569-10-19 ดูหัวข้อ "โครงหน้า") · ตัวเลขอ่างทั้งหมดอยู่ที่การ์ดอ่างเดิมของหน้าที่เดียว
- **อ่างเล็กของศูนย์ฯ แพร่ (`bind.type = 'small-reservoir'`)** = รายงานรายสัปดาห์พิมพ์มือ ไม่ใช่ค่าสด → โหนดไม่ขึ้นป้าย "ค่าสด" และไม่ขึ้น "ไม่มีค่าสดในระบบ" (หน้ามีการ์ดอ่างเล็กของตัวเอง) · note ของโหนดบอกว่าไม่ใช่ค่าสด
- สรุปจำนวนของขั้น "ในตำบล" ไม่เขียนจำนวน 0 (`systemCountsText`) · เกิน 9 เขียน "ประมาณ" (นับจากภาพ)
- **สองผังวาดไม่ตรงกัน** → ใช้ผังของตำบลตัวเอง จดความขัดกันไว้ใน `omitted` ของทะเบียน ไม่ตัดสินแทน
- จำนวนอ่าง/แผนก่อสร้าง (และหนอง/ฝายของทุ่งแค้ว) ในทะเบียนต้องตรงกับผังเคลื่อนไหว — เทสต์ตรวจให้ กันตัวเลขลอยจากภาพ
- **เจ้าหน้าที่ไม่มีงานเพิ่ม** — ไม่มีช่องกรอก/ฟอร์ม/ปุ่มแก้ · ปุ่มมีแค่ย่อ/ขยายรายการ · ผังผิดแก้ที่ไฟล์ทะเบียน (แจ้งผู้ดูแลระบบ)
- ไม่ใช่เอกสารทางราชการ · ไม่อ้างมาตรา · ถ้า อบต. จะแนบรายงานทางการ ต้องยืนยันกับระเบียบฉบับปัจจุบัน
- ไม่โฮสต์ภาพผัง (ถอดเป็นข้อมูล) · ยังไม่ขออนุญาตศูนย์ฯ (เจ้าของรับความเสี่ยงไว้) · ถอนได้ที่ `WATER_SYSTEM_TENANTS` จุดเดียว

## เพิ่มตำบลใหม่ (5 ขั้น)
1. เปิดผังน้ำจังหวัดแพร่ หาสายน้ำของตำบล · ผังตำบลของตัวเอง · ผังตำบลเพื่อนบ้านต้นน้ำ/ปลายน้ำ (ดึงรายชื่อ+ไฟล์จาก `view_diagram_district.php`)
2. สร้าง `src/lib/waterSystem/<ตำบล>.js` ตามรูปแบบ `namlao.js` (sources + upstream/inside/downstream + relations + omitted) — "ในตำบล" สรุปจากผังเคลื่อนไหวของตำบลนั้น ไม่ซ้ำรายละเอียด
3. เพิ่ม 1 บรรทัดใน `SYSTEMS` และ `WATER_SYSTEM_TENANTS` (+ `SYSTEM_PREVIEW_SCOPES`) ใน `model.js` · ป้ายความสัมพันธ์ต้องครบทุกอ่าง/สถานีระดับน้ำที่ อปท. นั้นเห็น
4. ซ้อนภาพที่ถอดกับผังต้นฉบับตรวจ · ลงรายการ `omitted` (ผังมีแต่ไม่ได้ใส่) ทุกอย่างที่ไม่ใส่พร้อมเหตุผล — เก็บไว้ให้ อบต. ยืนยัน ไม่ขึ้นหน้าเว็บ
5. เทสต์ + ดูบน demo (`?system=<id>`) ก่อนเปิดให้ อปท. จริง · อัปเดตตารางใน `scripts/check-phrae-diagram.mjs`

## ผังต้นฉบับเปลี่ยน
`npm run check:phrae-diagram` (มือ อ่านอย่างเดียว ~9 คำขอ) เทียบวันที่แก้/ETag/ขนาดของไฟล์ผังที่ใช้ (จังหวัด + 7 ตำบล) + ชื่อไฟล์ผังตำบลในหน้ารายการกับค่าที่จดไว้ (18–19 ต.ค. 2569) — เจอไฟล์เปลี่ยนแล้วให้เปิดผังใหม่เทียบกับทะเบียนแล้วถอดซ้ำ · แนะนำรันทุกต้นฤดูฝน/ฤดูแล้ง

## ที่ต้องให้ อบต. ยืนยัน (ไม่บล็อก)
**น้ำเลา:** จุดต่อสายแม่ถางของผังน้ำเลากับสายหลักของผังบ้านเวียง · ผังบ้านเวียงวาดเส้นจากสายหลักตอนล่างขึ้นไปยังอ่างแม่คำปอง (ไม่อธิบาย ไม่ตีความ) · อ่างห้วยทรายขาว/เด่นควาย/ห้วยขึมโยธินฯ มีแหล่งค่าสดไหม · ห้วยเหล็ก/ห้วยวัวไหลไปไหน
**ตำหนักธรรม:** "น้ำแม่คำมี" = "ลำห้วยแม่คำมี" (ผังร้องเข็ม/แม่คำมี) สายเดียวกันไหม · ต้นทางของคลองชลประทานแม่ยมฝั่งซ้าย (มาจากฝายแม่ยมไหม) และรับน้ำจากน้ำแม่คำมีหรือไม่ · ฝาย ม.12 แผนก่อสร้างหรือซ่อมแซม (สองผังสีไม่ตรงกัน) · สถานี YOM003 อยู่เหนือหรือใต้จุดที่น้ำแม่คำมีลงแม่น้ำยม · อ่างแม่คำปอง/แม่ถางไม่ไหลผ่านน้ำแม่คำมีใช่ไหม (ใช้ผังจังหวัดตอบไว้แล้ว ขอให้ยืนยัน)
**ทุ่งแค้ว:** แหล่งต้นน้ำของห้วยเฮือ/ยอย/ปุ่ยนอกตำบล (ขอบบน ติด ต.เวียงต้า) · ทิศน้ำและปลายทางของคลองชลประทานฝายแม่ยมฝั่งขวา/ลำเหมืองแม่หม้าย · ชื่อห้วยกลางผัง 4 เส้น · สถานี YOM003 อยู่เหนือหรือใต้ตำบล
