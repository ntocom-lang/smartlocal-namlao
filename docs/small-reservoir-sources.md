## ต้นทางและข้อจำกัด

- หน้า HTML: `https://www.phraepao.go.th/officechief/water/views_r_id.php?id_dam=N` — ตารางล้วน ไม่มี API ไม่มีพิกัด ไม่ระบุแหล่งที่มาของตัวเลข ไม่มีเงื่อนไขการใช้ (ไม่มี robots.txt)
- ใบรับรอง TLS ผ่านการตรวจปกติ (Google Trust Services) และอยู่หลัง Cloudflare — Worker ปิดการตรวจใบรับรองไม่ได้ จึงตรวจก่อนเลือกวิธีนี้
- อ่างขนาดเล็กอัปเดตรายสัปดาห์ด้วยมือ ลงวันที่ทีละอ่าง (14 ต.ค. ห้วยปุยขึ้นรายงานใหม่แล้ว ห้วยยอยยังเป็น 6 ต.ค.) ไม่ใช่ค่าวัดต่อเนื่อง
- ⚠️ **ป้ายสถานการณ์ของต้นทางเชื่อไม่ได้** — ห้วยปุย 46.05% ขึ้นว่า "น้ำมาก" ส่วน 87.35% ขึ้นว่า "น้ำดี" ตัวอ่านทิ้งป้ายนั้นทั้งหมด ใช้ % อย่างเดียว และ **ไม่ลงสีสถานการณ์**: ยังไม่ได้ยืนยันว่าตาราง 5.8/5.16 (`DAM_LEVELS`) ใช้กับอ่างขนาดเล็กได้ ถ้าจะลงสี ต้องยืนยันตารางก่อนแล้วใช้ `damLevel()` เดิม
- % กับปริมาตรคลาดกันได้ถึง ~3.4 จุด เพราะปริมาตรปัดทศนิยม 2 ตำแหน่ง (วัดจากข้อมูลจริง 357 แถว) ด่านตรวจใช้ 6 จุดเพื่อกันคอลัมน์เลื่อน
- ตัวเลขซ้ำเดิมเป็นสัปดาห์ๆ ได้: ห้วยยอยซ้ำ 82.27% ถึง 20 รายงานติดกัน (1 ต.ค. 2567 – 11 ก.พ. 2568) · ค่าโดดมีจริง (15 ต.ค. 2568 = 71.73% คั่นระหว่าง 94–95%) แสดงตามต้นฉบับ ไม่ซ่อนและไม่เดาว่าผิด
- มีแถววันที่ผิด (ปี 0004 ที่ id 37) และวันที่ซ้ำ (ห้วยปุย 2 แถว) → ทิ้งแถว
- ไม่ส่งเข้า Telegram / แถบเตือนหน้าแรก / ภาพแชร์ ตั้งใจ: รายสัปดาห์ พิมพ์มือ มีค่าโดดและค่าซ้ำ ถ้านำไปเตือนจะเตือนผิดบ่อย (บทเรียน #330)

## การทำงานและค่าใช้จ่าย

`GET /api/small-reservoir?id=50|30` (`worker/phraeReservoir.js`) แพตเทิร์นเดียวกับ `/api/hydro-hourly`: ดึงเมื่อเปิดหน้า ตัวอ่าน `parseReservoirHtml()` ใน `src/lib/smallReservoirs.js` ไล่ด้วย `indexOf` ไม่ใช้ regex กวาดทั้งหน้า (งบ CPU 10 ms ต่อคำขอของ Worker ฟรี) หยุดที่ 60 แถว · cache ที่ edge 6 ชม. ต่อศูนย์ข้อมูล Cloudflare · ต้นทางล่มใช้ของเก่าได้ไม่เกิน 14 วัน (ขึ้นป้าย) เกินนั้น 503 และหน้าเว็บขึ้นลิงก์ต้นฉบับ

ไม่มี cron / secret / Edge Function / ฐานข้อมูล / ตัวเฝ้าระวัง → deploy โดย CI หลัง merge เท่านั้น · ไม่ผูกคำสั่ง Supabase จึงไม่ถูกกับดัก "มือถือค้างเพราะ token refresh" · ใช้ Free Tier เดิม ไม่เพิ่มบริการเสียเงิน ภาระดูแลคือแก้ตัวอ่านเมื่อต้นทางเปลี่ยนหน้า (ตัวอ่านโยน error แทนการเดา)

ข้อแลกเปลี่ยน: ไม่มีประวัติถาวรในฐานข้อมูลเรา (ต้นทางส่งประวัติทั้งตารางมาให้อยู่แล้ว) · ต้นทางล่ม edge ที่ไม่เคยจำไว้จะแสดงป้ายพร้อมลิงก์ ไม่มีตัวแจ้งเจ้าหน้าที่
