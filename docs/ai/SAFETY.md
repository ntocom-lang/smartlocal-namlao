# SAFETY.md — กติกาความปลอดภัยสำหรับ agent ที่รันในเครื่อง (IDE/CLI)

ต้นฉบับของบล็อก [SAFETY สำหรับ agent ใน IDE] ที่ `scripts/ai-sync.mjs` sync ไปยัง AGENTS.md
แยกออกมาเป็นไฟล์ต่างหากเพราะเดิมบล็อกนี้อยู่แค่ใน AGENTS.md ซึ่งเป็นไฟล์ generated
— ถ้า regenerate โดยไม่มีต้นฉบับ บล็อกนี้จะหายไปทั้งก้อน

ใช้เฉพาะกับ agent ที่แก้ไฟล์ในเครื่องได้ จึงไม่ sync ไป web-snippets.md
(AI ฝั่งเว็บแตะไฟล์ไม่ได้อยู่แล้ว)

- ห้าม commit/push เอง ห้ามแก้ .env, credential, secret, CI config โดยไม่ถาม
- ห้ามลบไฟล์หรือ git reset --hard / force push
- ห้ามอ่านหรือส่งไฟล์ที่มีข้อมูลส่วนบุคคลของประชาชนออกนอกเครื่อง
