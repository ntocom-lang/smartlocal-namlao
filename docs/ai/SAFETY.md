# SAFETY.md — กติกาความปลอดภัยสำหรับ agent ที่รันในเครื่อง (IDE/CLI)

ต้นฉบับของบล็อก [SAFETY สำหรับ agent ใน IDE] ที่ `scripts/ai-sync.mjs` sync ไปยัง AGENTS.md
แยกออกมาเป็นไฟล์ต่างหากเพราะเดิมบล็อกนี้อยู่แค่ใน AGENTS.md ซึ่งเป็นไฟล์ generated
— ถ้า regenerate โดยไม่มีต้นฉบับ บล็อกนี้จะหายไปทั้งก้อน

ใช้เฉพาะกับ agent ที่แก้ไฟล์ในเครื่องได้ จึงไม่ sync ไป web-snippets.md
(AI ฝั่งเว็บแตะไฟล์ไม่ได้อยู่แล้ว)

[SAFETY สำหรับ agent ใน IDE]
- ห้าม commit/push เอง ห้ามแก้ .env, credential, secret, CI config โดยไม่ถาม
- ห้ามลบไฟล์หรือ git reset --hard / force push
- ห้ามอ่านหรือส่งไฟล์ที่มีข้อมูลส่วนบุคคลของประชาชนออกนอกเครื่อง
  ถ้าเจอไฟล์ลักษณะนี้ ให้หยุดและแจ้งผม (PDPA)
- ก่อนแก้ไฟล์เกิน 3 ไฟล์ ให้เสนอแผนก่อนแล้วรอ approve
- ห้ามยุ่งงานที่ session อื่นทำค้างไว้ — ไฟล์ที่ `git status` ขึ้น M แต่ยังไม่ commit
  ถือเป็นงานของคนอื่น ห้าม checkout ทับ ห้าม stash ห้าม reset ห้ามแก้ไฟล์เดียวกัน
  งานที่ยังไม่ commit ทับแล้วกู้ไม่ได้ (ไม่มีใน reflog) ต่างจากคอมมิตที่ย้อนได้เสมอ
  ถ้าจำเป็นต้องแตะ ให้หยุดแล้วขออนุญาตก่อนทุกครั้ง
- ทำงานใน `git worktree` แยกที่ตัดจาก `origin/master` เสมอ ไม่สลับสาขาในทรีหลัก
  (repo นี้ merge แบบ squash สาขาที่ merge แล้วจะชนกับ master ตลอดไป)
  `git worktree add /d/tmp/wt-<ชื่อ> -b <สาขา> origin/master`
- อาการ "แก้แล้วแต่ที่เห็นยังเหมือนเดิม" ให้ตรวจ 2 ชั้นก่อนสรุปว่าเป็น cache
  (1) บันเดิลบน production มีของใหม่จริงไหม — ไล่ chunk จาก index.js ถึงไฟล์ที่ใช้จริง
  (2) working tree ในเครื่องตามหลัง master กี่ commit และไฟล์นั้นมีใครแก้ค้างไว้ไหม
