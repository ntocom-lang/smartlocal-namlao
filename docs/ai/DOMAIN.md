# DOMAIN.md — ความเชี่ยวชาญเฉพาะโปรเจกต์นี้ (SmartLocal v1.1)

ไฟล์นี้เสริม `docs/ai/CORE.md` **เฉพาะโปรเจกต์นี้เท่านั้น** — ห้าม sync เนื้อหาไฟล์นี้ไปไฟล์ global
(`~/.claude/CLAUDE.md`, `~/.gemini/GEMINI.md`) เพราะไฟล์ global ต้องใช้ได้กับทุกโปรเจกต์
ถ้าอยากเปลี่ยนสายงานสำหรับโปรเจกต์อื่น ให้สร้าง `docs/ai/DOMAIN.md` ใหม่ของโปรเจกต์นั้นแทน
ไม่ต้องแก้ไฟล์นี้หรือไฟล์ global

[มาตรฐานการพิมพ์เอกสารราชการ — บังคับทุกใบ]
เอกสารที่พิมพ์ออกกระดาษทุกชนิดต้องยึดค่าเดียวกันจาก `src/lib/govDocStyle.js`
ห้ามเขียน font-family / font-size / @page margin ซ้ำในไฟล์ปลายทาง ให้ import มาใช้
- ฟอนต์ `THSarabunPSK` (ชื่อ family ติดกัน ห้ามเว้นวรรค ไม่งั้นตกไปใช้ฟอนต์ระบบเงียบๆ)
- ขนาด 16pt · ระยะบรรทัด single · ขอบซ้าย 3 ซม. ขอบขวา 2 ซม. (พื้นที่พิมพ์ 16 ซม.)
- `font-size-adjust: 0.45` บังคับเสมอ — เครื่องเจ้าหน้าที่ส่วนใหญ่ไม่ได้ลงฟอนต์ราชการ
  ค่านี้ทำให้ฟอนต์ที่ตกมาแทนพิมพ์ออกมาขนาดเท่ากัน ใบที่ต้องจบ 1 หน้าจะได้ไม่หลุด
- อ้างอิง: หนังสือสำนักนายกรัฐมนตรี ที่ นร ๐๑๐๖/ว ๒๐๑๙ (ตามระเบียบสำนักนายกรัฐมนตรี
  ว่าด้วยงานสารบรรณ พ.ศ. ๒๕๒๖) — ค่าเหล่านี้คัดจากคู่มือส่วนราชการที่อ้าง ว ๒๐๑๙ อีกทอด
  ยังไม่ได้ยืนยันกับตัวบทต้นฉบับ ถ้าจะอ้างอิงเป็นทางการต้องเปิด ว ๒๐๑๙ ฉบับจริงก่อน

กระดาษใช้ A4 ทุกใบ ไม่มีข้อยกเว้นเรื่องขนาดกระดาษ (บัตรเข้าใช้งานระบบเคยเป็น A5
ย้ายมาเป็น A4 แล้ว) เลือก **แนวตั้งหรือแนวนอนตามความเหมาะสมของเนื้อหา** ได้ทั้งสองแนว
แต่ขอบกระดาษกับฟอนต์ใช้ค่าเดียวกันทั้งคู่ — แนวนอนส่ง `govPageCss({ size: 'A4 landscape' })`

ข้อยกเว้นมีระดับเดียวคือ "ขนาดตัวอักษร" ไม่ใช่ขอบกระดาษหรือฟอนต์
- เอกสารตารางที่คุมขนาดเองรายช่อง (บังคับ 16pt แล้วคอลัมน์ไม่พอ) ให้ใช้
  `govDocFontIdentityCss()` แทน `govDocFontCss()` — ได้ฟอนต์ + font-size-adjust
  เหมือนใบอื่น แต่คงขนาดรายช่องไว้ เช่น `fleetForm4Print.js` (แบบ 4 บันทึกการใช้รถ)
  และรายงานตารางใน `ComplaintsManager.jsx`
- แบบพิมพ์ตามกฎหมายที่ต้องลอกเลย์เอาต์ต้นฉบับ เช่น `buildingPermitPrint.js` ยังไม่แตะ
- ช่องรหัสผ่าน/ชื่อผู้ใช้ใน `accountCardPrint.js` ใช้ monospace เพราะต้องแยก 0 กับ O
  และ 1 กับ l ให้เห็น ผู้สูงอายุพิมพ์ผิดตัวแล้วล็อกอินไม่ได้
ทุกข้อยกเว้นต้องเขียนเหตุผลกำกับไว้ที่จุดเรียกใช้เสมอ

⚠️ ค่า em/% ในเลย์เอาต์เดิมของแต่ละใบถูกไล่ไว้ตามขนาดฟอนต์เก่า เปลี่ยนขนาดแล้ว
ต้องวัดใหม่ทุกครั้ง (เคสจริงที่เจอ: ชื่อผู้ขอตกบรรทัด, เส้นลงนามสั้นจนเซ็นไม่ได้,
ช่องลงนาม 3 คอลัมน์ล้นขอบกระดาษ 3px)
