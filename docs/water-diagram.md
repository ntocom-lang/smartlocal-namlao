# ผังน้ำตำบล (เคลื่อนไหว) — ที่มา ข้อจำกัด วิธีแก้ และวิธีถอน

หน้า `/water-situation` ของ อปท. ที่อยู่ใน `WATER_DIAGRAM_TENANTS` (`src/lib/waterDiagram/model.js`) มีส่วน "ผังน้ำตำบล…" ต่อจากการ์ดอ่างเก็บน้ำขนาดเล็ก (`WaterDiagram.jsx`)
**แต่ละ อปท. ได้ผังของตำบลตัวเอง** · อปท. ที่ยังไม่มีผังไม่เห็นหัวข้อนี้เลยและไม่โหลดโค้ดส่วนนี้ (lazy import) · ไม่โชว์ผังของที่อื่นแทน

| อปท. | ผัง | ไฟล์ข้อมูล | ค่าสดบนผัง |
|---|---|---|---|
| ทุ่งแค้ว (`thungkaew`) | ผังน้ำตำบลทุ่งแค้ว (ผังต้นฉบับ 9 พ.ค. 2567) | `thungkaew.js` | อ่างห้วยยอย/ห้วยปุ่ย (รายงานอบจ.) · ฝน RES038 · ระดับน้ำ YOM003 |
| ตำหนักธรรม (`tamnaktham`) | ผังน้ำตำบลตำหนักธรรม (9 พ.ค. 2567) | `tamnaktham.js` | ระดับน้ำ Y.38 บ้านแม่คำมีตำหนักธรรม (ห่างสำนักงาน 0.7 กม. บนน้ำแม่คำมี) |
| น้ำเลา (`namlao`) | ผังน้ำตำบลน้ำเลา (30 เม.ย. 2567) | `namlao.js` | อ่างแม่คำปอง (ThaiWater รายวัน) · ฝนบ้านบุญแจ่ม STN0911 · ฝน RES040 (อ่างห้วยขึมโยธินฯ) — ไม่ใส่ระดับน้ำ YOM003 (ห่าง 14.1 กม. นอกตำบล) |

## สิ่งที่ผังเป็น และไม่เป็น

- **เป็น**: ภาพประกอบ "ทิศทางน้ำตามผัง" ที่ศูนย์บริหารจัดการทรัพยากรน้ำจังหวัดแพร่วาดไว้ (ไฟล์ภาพลงวันที่ตามชื่อไฟล์) **วาดใหม่ด้วย SVG** ไม่ได้คัดลอก/โฮสต์ภาพต้นฉบับ มีลิงก์ไปผังต้นฉบับ
- **ไม่เป็น**: การวัดว่าตอนนี้มีน้ำไหลจริง — ฝาย คลอง หนอง ไม่มีเครื่องวัด เส้นที่วิ่งไม่ผูกกับค่าใดๆ และไม่เปลี่ยนตามระดับน้ำ · ไม่ใช่ประกาศเตือนภัย · ไม่ใช่ผลงานของ อบต.
- คำกำกับนี้อยู่บนหน้าเสมอ (เทสต์ตรวจข้อความ) ห้ามเอาออก

## ออกแบบให้ผู้ใช้/ประชาชนไม่ต้องถามซ้ำ (เจ้าของระบบสั่ง 2569-10-16)

ทุกผังใช้กติกาเดียวกัน — ใช้ข้อมูลในไฟล์ผังเอง ไม่มีช่องกรอกให้เจ้าหน้าที่:
1. **ทุกสัญลักษณ์ที่วาดมีคำอธิบาย** (คำอธิบายสัญลักษณ์ใต้ผังแสดงเฉพาะที่ผังนั้นมีจริง — ผังไม่มีอ่างก็ไม่มีบรรทัดอ่าง) เทสต์ตรวจ
2. **กล่อง "ที่มา" บอกอายุผังต้นฉบับ** และรายการ **"ที่ผังต้นฉบับมีแต่เราวาดต่างไป หรือไม่ได้วาด พร้อมเหตุผล"** (`omitted` ในไฟล์ข้อมูล) กันคำถามว่าทำไมไม่เหมือนต้นฉบับ
3. ป้ายค่าสดทุกป้ายบอกชื่อสถานี ระยะ เวลาวัด ไม่ลงสีสถานการณ์ · ไม่มีค่า/ค่าค้าง = บอกตรงๆ ไม่เป็น 0 หรือ "ปกติ"
4. **ไม่วาด/ไม่เขียนของที่ไม่ชัด** — ชื่อที่อ่านไม่ออกไม่เขียน สัญลักษณ์ที่คำอธิบายผังไม่นิยามไม่วาด (ลงใน `omitted`)
5. โครงสร้างที่ผังวาดเป็นสีแดง (= "จะก่อสร้างใหม่" ตามคำอธิบายผัง) วาดเป็นเส้นประ/แท่งแดง + แท็ก "แผนก่อสร้าง · ไม่เคลื่อนไหว" ในโหมดรายการ ไม่เคลื่อนไหว
6. ของที่ผังไม่ระบุความสัมพันธ์ (เช่นคลองตัดน้ำแม่คำมีแต่ไม่ระบุว่ารับน้ำ) เขียนว่า "ผังไม่ระบุว่า…" ไม่เดา

## สิ่งที่วิ่ง และสิ่งที่ไม่วิ่ง

วิ่ง: ลำหลัก (main) · ทางผันเส้นหนา (big) · ลำห้วยสาขา (branch) · แม่น้ำ (river) — เฉพาะที่ `status: existing` ตามผัง · ทุ่งแค้ว 19 เส้น · น้ำเลา 9 เส้น · ตำหนักธรรม 3 เส้น (น้ำแม่คำมี + คลองชลประทานแม่ยมฝั่งซ้าย + แม่น้ำยม ผังวาดลูกศรทิศเดียว)
ไม่วิ่ง: ลำห้วยเล็ก (ลูกศรนิ่ง) · คลองที่ผังวาดลูกศรสองปลาย ไม่ระบุทิศ (ระยิบ) · โครงสร้างชำรุด/แผนก่อสร้าง — กฎอยู่ที่ `isAnimated()` ใน `model.js` ที่เดียว
หยุดได้ด้วยปุ่ม · หยุดเองเมื่อผังอยู่นอกจอหรือแท็บถูกซ่อน · เคารพ "ลดการเคลื่อนไหว" ของระบบปฏิบัติการ

## ต้องให้ อบต. ยืนยัน (ยังไม่บล็อกการทำ แต่ก่อนเปิดกับ อปท. จริงควรให้ดูครั้งเดียว — ผังอายุ ~17 เดือน สถานะโครงสร้างอาจเปลี่ยนไป)

### ทุ่งแค้ว
1. **ชื่อห้วยแนวตั้ง 4 เส้นกลางภาพ** — ป้ายในผังเขียนตะแคง อ่านจากภาพขยายได้ว่า "ห้วยจำค่า · ห้วยย่าเฟย · ห้วยแกด · ห้วยจำ" แต่ยังไม่มีใครยืนยัน หน้าจริงจึง **ไม่ใส่ชื่อ** (เทสต์ห้ามชื่อเหล่านี้โผล่) · ได้ชื่อแล้ว: เติม `T(...)` ใน `thungkaew.js` + แก้ข้อความสายที่ 4 + ลบข้อความใน `omitted` + ปรับเทสต์
2. **รางส่งน้ำชำรุด 2 จุด** — ผังวาดลายแดง แต่คำอธิบายสัญลักษณ์ของผังบอกว่า "ชำรุด/ซ่อมแซม ใช้สีน้ำเงิน" · ซ่อมแล้ว: เปลี่ยน `status: 'repair'` เป็น `'existing'`
3. **สถานีสูบน้ำ 2 จุดกับเส้นแดง** — แดง = "จะก่อสร้างใหม่" · สร้างเสร็จแล้ว: เปลี่ยน `status` เป็น `existing`
4. **ทิศน้ำในคลองชลประทานฝายแม่ยมฝั่งขวา** — ผังวาดลูกศรสองปลาย · ได้ทิศ: เปลี่ยนเป็นเส้น `main` ทิศเดียว

### น้ำเลา
1. **อ่างแม่คำปอง ตอน 2 + ฝายแดง 3 แท่ง** (ฝายบนลำน้ำ 2 + ฝายบนห้วยหล่าย 1) — ผังเขียนสีแดง = "จะก่อสร้างใหม่" · สร้างเสร็จแล้ว: เปลี่ยน `status` เป็น `'existing'` ใน `namlao.js` (+ถอดแท็กในสายน้ำ + แก้เทสต์)
2. **พื้นที่ลายขีดแดงทางซ้ายล่าง** — คำอธิบายผังไม่นิยามลายขีดแดง (มีแต่ "พื้นที่แล้งซ้ำซาก" สีชมพูล้วน และ "พื้นที่ท่วมซ้ำซาก" สีฟ้า) เราวาดเป็นกรอบเส้นประเทา + ป้ายบอกตรงๆ **ห้ามเขียนว่าแล้ง/ท่วมจนกว่า อบต. ยืนยัน** (เทสต์ห้ามคำนี้บนผัง) · ยืนยันแล้ว: ปรับ `area-unknown`/`chip-area` + `omitted` + เทสต์
3. **สามเหลี่ยม 3 จุดฝั่งตะวันออกชี้ไปทางขวา** (อ่างห้วยทรายขาว · อ่างเด่นควาย · สามเหลี่ยมบนห้วยขึม) — วาดตามผัง ไม่บอกเหตุผลของทิศ · และป้าย "อ่างห้วยขึมโยธินฯ" ที่เขียนไว้ใต้ลงมา เราอ่านว่าเป็นอันเดียวกับสามเหลี่ยมบนห้วยขึม (ใช้ผูกป้ายฝน RES040) — ผังไม่ลากเส้นเชื่อม
4. **ห้วยเหล็ก · ห้วยวัว (มุมขวาบน)** — ผังเขียนชื่อไว้แต่ไม่มีเส้นลำห้วย · **ฝายไม่ระบุชื่อ** ถัดจากฝายท่าเรือ 3 แห่งบนห้วยฝั่งซ้ายล่าง · ลำห้วยไม่ระบุชื่อ 3 สายที่ y เดียวกับห้วยเตาปูน
5. เส้นขอบเขต: ผังวาดเส้นประแดง (ตามคำอธิบายผัง = เขตหมู่บ้าน แต่ผังเขียนชื่อตำบลข้างเคียงกำกับ) เราวาดเป็นเส้นประเทาชนิดเดียว ไม่แยกตำบล/หมู่บ้าน

### ตำหนักธรรม
1. **สถานีสูบน้ำ P 3 จุด + ฝายแม่คำมีหมู่ 1 + ฝายแม่คำมีหมู่ 12** — ผังเขียนสีแดง = "จะก่อสร้างใหม่" · สร้างเสร็จแล้ว: เปลี่ยน `status` เป็น `'existing'` ใน `tamnaktham.js` (และถอด tag/สถานะในสายน้ำ + แก้เทสต์ `EXPECT`)
2. **"ฝายแม่คำมี ม.2"** — ผังเขียนชื่อไว้แต่เห็นเป็นแท่งแดงแท่งเดียวกับฝายหมู่ 12 จึงวาดแท่งเดียว · ถ้ามีฝาย ม.2 แยกจริง เพิ่ม `W(...)`
3. **คลองชลประทานแม่ยมฝั่งซ้ายรับน้ำจากน้ำแม่คำมีหรือไม่** — ผังวาดเส้นสองสายตัดกันโดยไม่ระบุ หน้าเว็บเขียนว่า "ผังไม่ระบุว่า…" · ได้คำตอบแล้วแก้ข้อความสายน้ำ
4. **ฝายไม่ระบุชื่อ 1 แห่ง** ถัดจากฝายแม่คำมี ม.3 ลงมา — ผังไม่เขียนชื่อ
5. สีของเขตหมู่บ้านริมน้ำแม่คำมี: ผังวาดแดงประ เราวาดเทา เพราะแดงในผังนี้ใช้หมายถึงแผนก่อสร้าง (ระบุไว้ในกล่องที่มาแล้ว)

- ข้อมูลผังเป็นไฟล์ล้วนใน `src/lib/waterDiagram/<ตำบล>.js` (พิกัดระบบเดียวกับภาพต้นฉบับ 2000×1125) ใช้ตัวสร้างร่วมจาก `builders.js` แก้ผ่าน git — ไม่มีหน้าแอดมิน ไม่มีฐานข้อมูล

- เพิ่มตำบล: (1) เปิดดูผังต้นฉบับ (`map_water_r.php` ของ phraepao.go.th — จับคู่ภาพกับตำบลจาก `<div id="popupN">` ต่อจากป้ายชื่อ ห้ามจับคู่ด้วย WebFetch) (2) ไฟล์ข้อมูลใหม่ (3) 1 บรรทัดใน `diagrams.js` (4) 1 แถวใน `WATER_DIAGRAM_TENANTS` + 1 บรรทัดใน `DIAGRAM_PREVIEW_SCOPES` (5) ความคาดหวังใน `EXPECT` ของ `tests/water-diagram.test.mjs` (6) ซ้อนผังที่วาดบนภาพต้นฉบับ 50% ตรวจตำแหน่ง · ต้องระบุก่อนว่าสถานีไหนอยู่ในตำบลนั้นและอ่างเล็กใดอยู่ในตำบล (ต้นทางไม่มีพิกัด) · ค่าสดอ่างกลาง (ThaiWater) ผูกด้วย `{ type: 'dam-station', code }`
- เทสต์: `npm run test:water-diagram` (ตรรกะ + ความสอดคล้องข้อมูลทุกผัง + เบราว์เซอร์ ทุกผัง ที่ 360/390/768/1280px) · ตรวจตำแหน่งกับภาพต้นฉบับ: ซ้อนผังที่วาดใหม่บนภาพ 50% ด้วยมือ (ไม่มีในรีโป)
