# ผังน้ำตำบลทุ่งแค้ว (เคลื่อนไหว) — ที่มา ข้อจำกัด วิธีแก้ และวิธีถอน

หน้า `/water-situation` ของ **ทุ่งแค้วและ demo** มีส่วน "ผังน้ำตำบลทุ่งแค้ว" ต่อจากการ์ดอ่างเก็บน้ำขนาดเล็ก (`WaterDiagram.jsx`)
อปท. อื่น (น้ำเลา ตำหนักธรรม) ไม่เห็นและไม่โหลดโค้ดส่วนนี้ (lazy import ตามทะเบียน)

## สิ่งที่ผังเป็น และไม่เป็น

- **เป็น**: ภาพประกอบ "ทิศทางน้ำตามผัง" ที่ศูนย์บริหารจัดการทรัพยากรน้ำจังหวัดแพร่วาดไว้ (ไฟล์ภาพลงวันที่ 9 พ.ค. 2567 ตามชื่อไฟล์) **วาดใหม่ด้วย SVG** ไม่ได้คัดลอก/โฮสต์ภาพต้นฉบับ มีลิงก์ไปผังต้นฉบับ
- **ไม่เป็น**: การวัดว่าตอนนี้มีน้ำไหลจริง — ฝาย คลอง หนอง ไม่มีเครื่องวัด เส้นที่วิ่งไม่ผูกกับค่าใดๆ และไม่เปลี่ยนตามระดับน้ำ · ไม่ใช่ประกาศเตือนภัย · ไม่ใช่ผลงานของ อบต.
- คำกำกับนี้อยู่บนหน้าเสมอ (เทสต์ตรวจข้อความ) ห้ามเอาออก

## ค่าสดบนผัง (4 ช่อง)

| ช่อง | แหล่ง | แสดงอย่างไร |
|---|---|---|
| อ่างห้วยยอย / ห้วยปุ่ย | `/api/small-reservoir` (Worker เดิมของการ์ด PR1 · รายสัปดาห์ พิมพ์มือ) | "อ่าง 73.2%" · เกิน 14 วัน = "ไม่มีรายงานใหม่" · ตัวเลขซ้ำ ≥ 3 รายงาน = เหลือง · ไม่ลงสีสถานการณ์ |
| ฝน RES038 (ที่อ่างห้วยยอย) | `get_public_water_situation` เดิม | "ฝน 12.5 มม." 24 ชม. · ค้างเกิน 3 ชม. = "ไม่มีค่าใหม่" |
| ระดับน้ำ YOM003 | `get_public_water_situation` เดิม | **ข้อเท็จจริงของสถานีพร้อมระยะ** "หนองม่วงไข่ ห่าง 4.8 กม. · ต่ำกว่าตลิ่ง 4.55 ม." ไม่ลงสี ไม่ตีความ (สถานีอยู่ห่างตำบล) |

ไม่มีค่า/ไม่มีสถานี = ป้ายขอบประ "ไม่มีค่าในระบบ" (ห้ามกลายเป็น 0 หรือ "ปกติ") · ห้วยเฮือไม่มีข้อมูลที่ อบจ. แสดง "ไม่มีข้อมูลในระบบ"
**demo** ไม่มีสถานี RES038/YOM003 ของทุ่งแค้ว ป้ายฝน/ระดับน้ำจึงขึ้น "ไม่มีค่าในระบบ" (หรือเป็นสถานีของ demo เอง) — ตั้งใจ ไม่ปลอมค่า

## สิ่งที่วิ่ง และสิ่งที่ไม่วิ่ง

วิ่ง: ลำหลัก (main) · ทางผันเส้นหนา (big) · ลำห้วยสาขา (branch) · แม่น้ำยม (river) — เฉพาะที่ `status: existing` ตามผัง (19 เส้น)
ไม่วิ่ง: ลำห้วยเล็ก (ลูกศรนิ่ง) · คลองชลประทานฝายแม่ยมฝั่งขวา (ผังวาดลูกศรสองปลาย ไม่ระบุทิศ → ระยิบ) · **รางส่งน้ำชำรุด 2 จุด** (ลายขีดแดง) · **สถานีสูบน้ำ 2 จุด + เส้นแดง** (เส้นประแดง "แผนก่อสร้าง") — กฎอยู่ที่ `isAnimated()` ใน `src/lib/waterDiagram/model.js` ที่เดียว
หยุดได้ด้วยปุ่ม · หยุดเองเมื่อผังอยู่นอกจอหรือแท็บถูกซ่อน · เคารพ "ลดการเคลื่อนไหว" ของระบบปฏิบัติการ

## ต้องให้ อบต.ทุ่งแค้วยืนยัน (ยังไม่บล็อกการทำ แต่ก่อนเปิดกับ อปท. จริงควรให้ดูครั้งเดียว)

1. **ผังอายุ ~17 เดือน** สถานะโครงสร้างอาจเปลี่ยนไปหลังทำผัง
2. **ชื่อห้วยแนวตั้ง 4 เส้นกลางภาพ** — ป้ายในผังเขียนตะแคง อ่านจากภาพขยายได้ว่า "ห้วยจำค่า · ห้วยย่าเฟย · ห้วยแกด · ห้วยจำ" แต่ยังไม่มีใครยืนยัน หน้าจริงจึง **ไม่ใส่ชื่อ** (เทสต์ห้ามชื่อเหล่านี้โผล่) · ได้ชื่อยืนยันแล้ว: เติม `T(...)` ใน `thungkaew.js` + แก้ข้อความสายที่ 4 + ปรับเทสต์
3. **รางส่งน้ำชำรุด 2 จุด** — ผังวาดลายแดง แต่คำอธิบายสัญลักษณ์ของผังบอกว่า "ชำรุด/ซ่อมแซม ใช้สีน้ำเงิน" ยังไม่แน่ใจว่าซ่อมแล้วหรือยัง · ซ่อมแล้ว: เปลี่ยน `status: 'repair'` เป็น `'existing'` (และเปลี่ยน `repair` เป็นฝายธรรมดา)
4. **สถานีสูบน้ำ 2 จุดกับเส้นแดง** — ผังเขียนสีแดงตามคำอธิบาย = "จะก่อสร้างใหม่" · สร้างเสร็จแล้ว: เปลี่ยน `status` เป็น `existing`
5. **ทิศน้ำในคลองชลประทานฝายแม่ยมฝั่งขวา** — ถ้าได้ทิศ เปลี่ยนเป็นเส้น `main` ทิศเดียวให้วิ่งได้

## แก้ผัง / เพิ่มตำบลอื่น

- ข้อมูลผังเป็นไฟล์ล้วน `src/lib/waterDiagram/thungkaew.js` (พิกัดระบบเดียวกับภาพต้นฉบับ 2000×1125) แก้ผ่าน git — ไม่มีหน้าแอดมิน ไม่มีฐานข้อมูล
- เพิ่มตำบล: ไฟล์ข้อมูลใหม่ 1 ไฟล์ + 1 แถวใน `WATER_DIAGRAM_TENANTS` + ปรับ `WaterDiagram.jsx` ให้เลือกผังตามทะเบียน (ตอนนี้มีผังเดียว) · ต้องเปิดดูผังตำบลนั้นและระบุก่อนว่าอ่างเล็กใดอยู่ในตำบล (ต้นทางไม่มีพิกัด)
- เทสต์: `npm run test:water-diagram` (ตรรกะ + ความสอดคล้องข้อมูล + เบราว์เซอร์) · ตรวจตำแหน่งกับภาพต้นฉบับ: ซ้อนผังที่วาดใหม่บนภาพ 50% ด้วยมือ (ไม่มีในรีโป)

## ถอน

ลบ `thungkaew` / `demo` ออกจาก `WATER_DIAGRAM_TENANTS` (`src/lib/waterDiagram/model.js`) จุดเดียว ผังหายทันที · ถ้าศูนย์ฯ แพร่ขอให้เอาข้อมูลออก ทำที่เดียวกัน
