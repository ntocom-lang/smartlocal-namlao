# ขนาดตัวอักษรหน้า /water-situation (ไม่เล็กกว่า 12px)

เพิ่ม 2569-10-28 หลังเทียบกับเว็บ ทต.หนองหอย (nh-water-monitor.web.app) แล้วพบว่าของเราเล็กกว่ามาก

| วัดบน production (มือถือ 390px) | หนองหอย | ของเรา (ก่อนแก้) |
|---|---|---|
| ข้อความเนื้อหาหลักที่เล็กกว่า 12px | 7% (ค่ากลาง 14px) | ตำหนักธรรม 54–60% · น้ำเลา 38–42% · ทุ่งแค้ว 55% (ค่ากลาง 11–13px) |
| ค่าต่ำสุด | 10px | 9.7px (ตัวเลขบนกราฟอ่างเล็ก) — และกราฟรายชั่วโมงเหลือ ~9.5px ที่แท็บเล็ต 768px |

ข้อมูลที่ต้องอ่านเช่น "วัน–เวลาวัด" "ต่ำกว่าตลิ่ง" ป้ายสถานะฝน/อ่าง ตัวเลขตารางรายชั่วโมง เคยเป็น 10–11px ผู้สูงอายุอ่านยาก (ตัวเลข % คำนวณจากจำนวนองค์ประกอบที่เป็นข้อความ ไม่ใช่ปริมาณตัวอักษร จึงอาจดูแรงกว่าความจริง)

## กติกา
- **12px เป็นเกณฑ์ที่ผมตั้งเอง (สมมติฐาน ไม่ได้อ้างมาตรฐานใด)** — เปลี่ยนที่ `MIN_PX` ใน `tests/water-text-size.playwright.mjs`
- ใช้กับ **แท็บ "สถานการณ์" ทั้งแท็บ** และ **ข้อความ HTML ของแท็บ "ผังน้ำตำบล"** · ใช้ขนาดที่ตามองเห็นจริง: ตัวอักษรใน SVG = font-size × (ความกว้างที่แสดง ÷ ความกว้าง viewBox)
- ห้ามกลับไปใช้ `text-[9px]`/`text-[10px]`/`text-[11px]` และ `font-size` ต่ำกว่า 12px ในส่วนที่ต้องอ่าน — เทสต์จะแดง

## ที่แก้
- `text-[10px]`/`text-[11px]` → `text-[12px]` ใน `WaterSituationPage.jsx` (28 จุด) · `SmallReservoirSection.jsx` · `RelationPill.jsx` · `WaterDiagram.jsx` · `WaterDiagramEdges.jsx` · CSS ของ `HydroHourlyPanel` / `WaterSituationPage` / `WaterDiagram`
- **กราฟระดับน้ำรายชั่วโมง** (`HydroHourlyPanel.jsx`): เดิม viewBox ตายตัว 400/740 ตามความกว้างหน้าจอ แต่กราฟอยู่ในคอลัมน์ที่แคบกว่าจอ (แท็บเล็ต 768px คอลัมน์ ~440px ย่อ 740 → ~0.6 เท่า) ตัวอักษร 16 หน่วยจึงเหลือ ~9.5px · แก้ให้ viewBox กว้างเท่าที่แสดงจริง (สเกล 1:1, `ResizeObserver`) ตัวอักษร 13px เสมอ
- **กราฟเส้นอ่างเล็ก**: ตัวหนังสือ "100%" (9 หน่วย) ในกราฟถูกถอดออก ย้ายคำอธิบายไปบรรทัดบนกราฟ "เส้นประ = 100% ของความจุ" — กราฟใช้ `preserveAspectRatio="none"` เส้นประอยู่ชิดขอบบน ถ้าขยายตัวอักษรเป็น 12px จะล้นขอบ/ทับจุดข้อมูลที่มักอยู่ใกล้ 100%
- **การ์ดสรุป 3 ใบบนจอ 360px** (กว้างใบละ ~104px): ตัวอักษร 12px ทำให้ป้าย "น้ำปานกลาง" หักเป็น 2 บรรทัด → ลดขอบการ์ด/ป้าย และซ่อนจุดสีหน้าป้ายเฉพาะจอ ≤400px (สีสถานะยังอยู่ที่แถบสีบนสุดของการ์ดและข้อความป้าย) · ที่ 320px "น้ำปานกลาง" ยังหัก 2 บรรทัดแบบไม่เสียหน้าตา (จอที่พบน้อยมาก)

## ที่ไม่ได้แก้ (ตั้งใจ)
- **ภาพโปสเตอร์ในแท็บผังน้ำตำบล** — เป็น SVG ขนาด A4 ที่ย่อลงจอมือถือ ตัวหนังสือในภาพ 8–11px (วัดบน production) เป็นธรรมชาติของโปสเตอร์ ไม่ใช่ข้อความที่ปรับได้ด้วยการเปลี่ยนคลาส · ทางอ่านจริงบนมือถือคือแท็บย่อย "รายการจุด" · การเพิ่มขนาดตัวหนังสือในโปสเตอร์ต้องออกแบบภาพใหม่ ให้เจ้าของระบบตัดสินใจแยก
- **ภาพแชร์ (PNG 1080px)** — วาดด้วย canvas ขนาดฟอนต์ของตัวเอง ไม่ได้มาจาก DOM ไม่ได้รับผลจากงานนี้
- ข้อความสถานะ "สถานการณ์/ผังน้ำตำบล" ของแถบแท็บ และส่วนหัว/เมนูของแอป (นอกหน้านี้)
